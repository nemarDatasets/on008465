# NeuralEcho MACS EEG ML Dataset By Subject

Generated by `step3_export_ml_by_subject.py`.

Preprocessing version: `ml_conservative`

This folder contains by-subject machine-learning exports derived from the
NeuralEcho MACS EEGLAB preprocessing pipeline.

Per subject:

- `eeg.npy`: float32 array with shape `(n_trials, n_channels, n_times)`.
- `labels.csv`: one row per trial. Row order matches the first dimension of `eeg.npy`.
- `labels.npz`: integer label arrays for NumPy/PyTorch/TensorFlow.
- `channels.csv`: channel labels and available coordinates.
- `times.npy`: EEGLAB epoch times in milliseconds.
- `metadata.json`: subject-level shape and sampling metadata.

Top-level files:

- `all_subjects_labels.csv`: concatenated labels for all subjects.
- `manifest.csv`: one row per exported source epoch file.
- `classes.json`: class-id maps and event-code maps.
- `extraction_summary.json`: dataset-level summary.

Example:

```python
import numpy as np
import pandas as pd

root = r"derivatives/machine_learning_exports/ml_conservative"
X = np.load(root + r"/S01/eeg.npy", mmap_mode="r")
labels = pd.read_csv(root + r"/S01/labels.csv")
y_mode = labels["mode_id"].to_numpy()
```
